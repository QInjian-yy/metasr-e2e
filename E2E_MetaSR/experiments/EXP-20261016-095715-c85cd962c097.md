两组共同前 51 轮的 WSI 顺序逐项一致。保存配置有三处不同：classification_encoder 从 spp 改为 spp_ln、epochs 从 100 改为 300、patience 从 15 改为 301；其余配置相同，两个停止规则在共同前 51 轮没有截断本次比较。LayerNorm 组后期训练拟合更强，但共同前 51 轮最佳 Val AUC 低约 0.056969，同 epoch 51 的验证 CE 也更高。当前单次运行不支持“SPP 未归一化是验证表现差的主要原因”这一假设，也没有证据支持直接沿 LayerNorm 方向继续长训会改善泛化。

已有 D4 完整增强的最佳 Val AUC=0.646529，但最佳轮 BACC=0.5，且深度不同，只能作为已有结果的背景，不能作为 LayerNorm 的严格对照。

建议先保留无 LayerNorm 的 D1/D4 完整增强作为参照，不因本组训练 AUC 较高就认定更好。若继续验证 LayerNorm，应使用已新增的 spp_d1_ln.yaml 与 spp_d1_ln_control.yaml，在相同 80 epochs / patience 20 下比较，再用多个 seed 检查稳定性；当前没有启动这些训练。若优先争取验证提升，可先做 D4 完整增强、SR=0、lr=2e-4、WD=1e-4 的单学习率对照，相对已有 D4 lr=1e-4 控制其余条件不变。

证据边界：仅 fold=0、seed=1，且本组为 60 轮快照；服务器 Git Commit 为空，原 D1 对照未回传 data_provenance.json，无法由回传文件证明两次服务器源码及逐图像内容完全一致。与 lr=5e-5、WD=1e-3、flip-only 和 D4 完整增强各组相比，本次回传 manifest/labels/split 的 SHA256 完全一致。未进行重复实验或显著性检验。
