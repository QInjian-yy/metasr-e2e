## 实验目的

在前组 SPP-1344 + RDN(D1) + 完整几何增强 + SR=0 基础上，将 Region microbatch 从 4 改为 1，并把计划训练上限从 100 改为 300、patience 从 101 改为 301，观察显存与后期泛化。实际路径为 LR [N,3,256,256] → RDN(D1) → Max SPP(1,2,4) → [N,1344] → Gated ABMIL(1344,128) → Linear(1344,2)。

本次仍使用原 256→8192、scale=32 数据，不是 native512/scale16 实验。其余保存配置为 lambda_sr=0、lr=1e-4、weight_decay=1e-4、freeze_meanshift=false、checkpoint_rdb=true、BF16、fold=0、seed=1；水平/垂直翻转各 0.5，rotation90=true。训练集离线评估与验证集无增强；没有 LayerNorm、Avg Pooling、MLP 或 Dropout。

本次计划 300 epochs / patience=301。当前 run_info.json 保持 incomplete，无结束时间；history 与 epoch 日志有 137 个完整 epoch，另有第 138 轮 84/174 张 WSI 更新，共 23922 次连续更新。日志末尾没有最终 summary 或异常堆栈，只按回传快照归档，不能确认服务器是否已停止、停止原因，也不记作完成 300 轮或正常早停。
